# 🪿 Space Goose

A tiny game made by the **De Anza Game Dev Club** while learning Git.

## How to play

1. Open `index.html` in your browser (double-click it).
2. Press **SPACE** (or click) to jump. Press again in the air to **double jump**.
3. Dodge the purple space rocks!

## Side quests (practice Git here!)

Do each quest as its own commit. Write a good message!

| Quest | What to change | Example commit message |
| --- | --- | --- |
| 🟢 Easy | Change `jumpForce` in `game.js` | `Make goose jump higher` |
| 🟢 Easy | Change `gooseColor` to your favorite color | `Make goose pink` |
| 🟡 Medium | Add your name to `CREDITS` (on a branch + pull request!) | `Add Sam to credits` |
| 🟡 Medium | Set `maxJumps` to 3 | `Add triple jump` |
| 🔴 Hard | Make the rocks a new color or shape | `Draw rocks as stars` |
| 🔴 Hard | Add a new sound when you get 100 points | `Play sound at 100 points` |

## The Git combo

```
git add .
git commit -m "Your message"
git push
```
